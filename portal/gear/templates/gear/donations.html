Recording a donation (admins)

  1. Pledge comes in — it appears above as New, and counts toward “pledged” on the wishlist. Email the donor; set Confirmed once it's agreed (opted-in donors then show on the wall), Declined if it won't fit.
  2. Earmarked for a slot (optional) — in NetBox, install a Planned module of the promised part in the empty bay and set its Donor field. It shows on the device page as wanted/pledged.
  3. Installed — the next hardware_inventory.py run replaces the planned module with the real one and carries Donor / Donated On over; set the pledge to Received. Without a planned module, set Donor / Donated On directly on the module (or on the device, for a whole chassis).
