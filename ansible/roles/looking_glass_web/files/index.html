    Peer with the looking glassAS 12276 · 206.197.187.1 · 2001:504:30::ba01:2276:1

    Every participant is required to peer with the SFMIX looking glass. The session is only for visibility and debugging: no routes are redistributed and no traffic is exchanged. It is used to:

    • validate your router configuration when you first connect
    • test configuration changes against a low-impact peer, with a self-service view of what the looking glass sees from you
    • see which prefixes are present at the exchange
    • give SFMIX operators a quick reachability check

    Quarantine VLAN. A parallel looking glass runs on the quarantine VLAN with the same addresses as production, so new participants can test their Ethernet, IP and BGP configuration before joining the production peering LAN. See the connection guide.
